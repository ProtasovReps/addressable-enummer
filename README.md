# Addressable Enummer 📋

Generate enums from addressable groups with one button click

## How To Use? 🤔

### 1. Import package into your project
### 2. Open Tools -> AddressableEnumer
### 3. If you can't see all of your groups click "Refresh"
### 4. Check all groups you need to make enums from
### 5. Press "Generate"
